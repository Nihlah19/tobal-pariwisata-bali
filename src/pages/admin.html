Konfigurasi Super Admin

Atur koneksi instance database Supabase baru (bila kuota gratis lama telah penuh) dan update Google Gemini AI API key langsung dari dashboard ini.

Database Supabase Baru (Database Switcher)

Jika database lama sudah penuh kuotanya, Anda dapat menghubungkan project Supabase baru di sini.

Dapatkan di: Supabase Dashboard > Project Settings > API > Project URL

Key publik yang digunakan frontend untuk otentikasi dan pembacaan data.

Panduan Mempersiapkan Database Baru:

Jika instance Supabase Anda baru dibuat dan masih kosong, buka menu SQL Editor di dashboard Supabase Anda, lalu jalankan file skema SQL yang ada di direktori project: supabase/schema.sql, supabase/migrations/002_dictionary.sql, dan supabase/migrations/004_grammar.sql.

Konfigurasi Google Gemini Vision AI

Atur kunci API model AI Vision Gemini untuk fitur 'Kenali Budaya' dari foto dan inferensi rekomendasi.

Dapatkan key gratis di Google AI Studio (aistudio.google.com).

Konfigurasi OpenAI (ChatGPT)

Gunakan kuota token OpenAI aktif Anda agar Chatbot Bli Kadek semakin cerdas, responsif, dan hemat kuota.

Dapatkan key dari dashboard akun OpenAI Anda (platform.openai.com/api-keys).
